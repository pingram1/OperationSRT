# Start Right Tutoring - App Context
- **Stack:** Node.js, Express, MongoDB, React.
- **Current State:** Secure, refactored, and equipped with a "School Pilot" cohort layer. 
- **The Core Differentiator:** The platform acts as an "AI-First Educational Copilot." It must continuously learn the user's habits, learning style, and proficiency based on every action they take inside the app.
- **The Goal:** Build an Adaptive Learning Engine. This engine must power:
  1. Dynamic Tutor Matching (the right tutor at the right time).
  2. Content Personalization (recommending challenges, coursework, and study nudges).
- **Data Available:** Student profiles, Tutor profiles, Booking history, Session completion data, Challenge attempts/success rates, and app usage telemetry (logins, session duration).
